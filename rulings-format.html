גרסה 1 · לאפליקציה ״פנקס חוק״

כלי העריכה המקומי לדף הראשי

אוסף הוא קובץ JSON עם רשימת פסקי דין. באפליקציה: לשונית פסיקה ← + ← ייבוא מקובץ JSON, או הוספה מקישור מתעדכן.

  • מקובץ: הקובץ נשמר במכשיר ואינו נשלח לשום מקום. כדי לעדכן, מייבאים שוב קובץ עם אותו id, והוא מחליף את הקודם.
  • מקישור: כתובת https שמחזירה את הקובץ. האפליקציה בודקת אותה כל כמה שעות ובמשיכה לרענון, ושומרת עותק במכשיר לשימוש בלי אינטרנט. אם ההורדה נכשלת או שהקובץ לא תקין, העותק השמור נשאר. השרת שמארח את הקובץ רואה את הבקשות.

את הקובץ אפשר לכתוב בכלי העריכה המקומי, שפועל כולו בדפדפן ולא שולח שום מידע, או להפיק מכל מערכת אחרת.

שדות האוסף

שדהתיאור
rulings חובהרשימת פסקי הדין (מערך).
titleשם האוסף, כפי שיוצג באפליקציה. בלעדיו משמש שם הקובץ או שם האתר.
idמזהה קבוע לאוסף. ייבוא חוזר של קובץ עם אותו id מחליף את האוסף.
descriptionתיאור קצר.
updatedתאריך העדכון, למשל 2026-09-27.
topicsסדר הנושאים (מערך של שמות). בלעדיו, הנושאים מוצגים לפי הסדר שבו הם מופיעים לראשונה.
format, versionסימון: "pinkas-hok/rulings" ו-1. לא חובה.

שדות של כל פסק דין

שדהתיאור
title חובהההלכה או העיקר בשורה אחת. פסק דין בלי title מדולג.
idמזהה קבוע. מומלץ מאוד: בלעדיו משמש מספר התיק, ומועדפים עלולים להתבלבל כשהקובץ משתנה.
caseRefמספר התיק, למשל בש"פ 2215/24.
partiesהצדדים, למשל פלוני נ' מדינת ישראל.
courtהערכאה.
judgesהשופטים.
dateתאריך ההחלטה: 2024-04-30 או 30.4.2024.
topicנושא.
subtopicתת-נושא בתוך הנושא.
tagsתגיות: מערך, או מחרוזת מופרדת בפסיקים.
principleהעיקרון המשפטי (ציטוט).
summaryסיכום.
noteהערה.
urlקישור https לפסק הדין המלא. קובץ PDF נפתח באפליקציה ונשמר במכשיר; דף אחר נפתח בתצוגה. קישור יחסי נקבע ביחס לכתובת האוסף.
relatedמזהים (id) של פסקי דין קשורים באותו אוסף, למשל ערכאה קודמת.

כללים

  • קובץ JSON בקידוד UTF-8, עד 50MB. שדות שאינם ברשימה מתעלמים מהם.
  • אפשר גם קובץ שכולו רשימה של פסקי דין, בלי האובייקט העוטף.
  • בקישור מתעדכן, האפליקציה שולחת If-None-Match ו-If-Modified-Since. שרת שמחזיר ETag ו-304 חוסך הורדות.
  • קישורי שיתוף של Dropbox, ‏GitHub ו-Google Drive מומרים אוטומטית לקישור הורדה ישיר.
